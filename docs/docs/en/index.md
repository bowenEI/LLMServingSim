# LLMServingSim Documentation

LLMServingSim is a cycle-level simulator for heterogeneous and disaggregated LLM serving systems.

- **New users:** start with [Getting Started](/en/getting-started/overview).
- **Run a simulation:** follow the [Quickstart](/en/getting-started/quickstart).
- **Understand the internals:** read the [Simulator Architecture](/en/simulator/architecture).
- **Look up configuration:** browse the [Reference](/en/reference/cli-flags).
- **Contribute:** see the [Contributor Guide](/en/contributor/welcome).

Use the language menu in the navigation bar to switch between the matching English and Chinese pages. English documentation is served under `/en`, and Chinese documentation is served under `/zh`.
